## `01` — About Me

I'm **Natnael Ayalew**, a software engineer focused on building modern web applications, digital products, and interactive user experiences.

My strongest area is **frontend engineering and UI**, while also working across the stack with backend systems, databases, APIs, authentication, deployment, and mobile applications.

I like taking an idea from:

`Figma → UI → Application → API → Database → Deployment`

and turning it into something people can actually use.

I'm especially interested in **SaaS, product development, business automation, AI/LLM applications, and modern web experiences**.
